Developer guide / 03

Mulai di VS Code.

Aplikasi ini adalah file HTML mandiri. Anda dapat mengeditnya tanpa memasang framework tambahan.

BEGINNER FRIENDLY

Langkah penggunaan

01 · Unduh file HTMLKlik tombol “Unduh HTML” di kanan atas halaman pembuat.
DOWNLOAD
02 · Buka folder di VS CodeJalankan VS Code → File → Open Folder, lalu pilih folder kerja Anda.
OPEN
03 · Edit fileBuka media-pembelajaran.html. HTML mengatur struktur, CSS tampilan, dan JavaScript interaksi.
EDIT
04 · Jalankan di browserSimpan file lalu buka dengan browser. Jika memakai ekstensi Live Server, klik kanan file → Open with Live Server.
PREVIEW
05 · Tambahkan aset lokalBuat folder assets untuk logo, gambar, dan video. Gunakan path relatif seperti assets/intro.mp4.
